# Git Workflow Helper

帮助开发者和团队建立高效的 Git 工作流程。

## When to Use This Skill

- 需要制定团队 Git 分支策略时
- 编写规范的 commit message
- 解决合并冲突
- 设置 Git hooks
- 配置 CI/CD 与 Git 集成

## Features

### 1. 分支策略建议
- Git Flow
- GitHub Flow  
- Trunk Based Development
- 根据团队规模推荐最佳策略

### 2. Commit 规范
- Conventional Commits 格式
- 语义化版本控制
- 自动生成 changelog

### 3. 冲突解决
- 分析冲突原因
- 提供解决方案
- 预防冲突的最佳实践

## Usage

```
帮我制定一个适合 5 人团队的 Git 分支策略
```

```
检查我的 commit message 是否符合规范
```
